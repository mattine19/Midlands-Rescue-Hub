# Midlands Rescue Hub

**Connecting animals in need with people who care.**

[View Live Website](https://mattine19.github.io/Midlands-Rescue-Hub/)

## About

Midlands Rescue Hub is a website concept focused on helping animal welfare organizations across the Midlands and South Carolina work together to support animals in need.

## Key Features

- **Project Mission:** Introduces the goal of supporting animal welfare organizations.
- **Submit a Request:** Outlines how animal placement requests could be submitted.
- **Match With Helpers:** Highlights connecting requests with potential volunteers.
- **Coordinate Care:** Emphasizes collaboration to help animals receive care.

## Documentation

The repository also includes a UML class diagram illustrating the proposed software architecture.

## Project Status

This project currently serves as a landing page and overview of the proposed platform. The animal-matching and coordination features are conceptual, not fully implemented.
